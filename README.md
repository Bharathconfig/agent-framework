# agent-framework
A framework for building, orchestrating and deploying AI agents and multi-agent workflows with support for Python and .NET.

## 📦 Microsoft Agentic Framework – 25 examples

See **[`microsoft-agentic-framework/`](microsoft-agentic-framework/README.md)**: 25 runnable, fully commented
Microsoft Agent Framework examples, from beginner agents to guardrails, multi-agent systems (MAS) and judge agents.
You only need to add your Azure OpenAI API key and endpoint to `.env`.
